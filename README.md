# Archery Studio — React starter

An original, responsive React + TypeScript + Vite website starter inspired by the *structure* of an archery training site. It does not include copied logos, images, source code, or proprietary content.

## Start

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Included

- Responsive header, navigation, hero, announcements, service cards and footer
- Routes for home, lessons, classes, events, event details, team, articles and contact
- Placeholder data and styles ready to customize

## Not yet implemented

- Real photos and brand assets
- Booking/payment integration, user accounts, CMS, newsletter service
- Real events data and persistence
- Contact form submission

Replace demo names, contact info and content before production use.
